# שיפרה גבות – אתר העסק

האתר בנוי מקבצים פשוטים (HTML, CSS, JavaScript), בלי מערכת ניהול ובלי תשלום על אירוח. הוא מתארח בחינם ב-GitHub Pages.

## מבנה האתר
| קובץ | מה יש בו |
|---|---|
| `index.html` | דף הבית: טיפולים, השיטה, גלריה, כלות, אקדמיה, המלצות, שאלות נפוצות ויצירת קשר |
| `kalot.html` | חבילות כלה ולוח זמנים להכנות |
| `horaot.html` | הוראות לפני ואחרי טיפול |
| `js/content.js` | ✏️ **כל התוכן שעורכים**: טלפון, וואטסאפ, רשתות חברתיות, מחירים, טיפולים, ביקורות, גלריה, שאלות נפוצות |
| `images/` | כאן מעלים את הלוגו ואת התמונות |

## איך מעדכנים תוכן (בלי לדעת לתכנת)
1. נכנסים ל-GitHub, לקובץ `js/content.js`, ולוחצים על סמל העיפרון ✏️.
2. משנים רק את הטקסט שבתוך המירכאות `"..."`.
3. לוחצים **Commit changes**. אחרי דקה-שתיים השינוי מופיע באתר.

### דוגמאות
- **מחיר:** `price: ""` משנים ל-`price: "₪80"`.
- **וואטסאפ:** `whatsapp: "972501234567"` (מספר בלי ה-0 הראשון, עם 972 בהתחלה).
- **לוגו:** מעלים את `logo.png` לתיקייה `images` (בכפתור Add file ← Upload files) ורושמים `logo: "images/logo.png"`.
- **תמונה לגלריה:** מעלים לתיקייה `images` ומוסיפים שורה ל-`gallery`:
  `{ src: "images/work1.jpg", caption: "מיקרובליידינג – לפני ואחרי" },`
- **ביקורת:** מוסיפים שורה ל-`reviews`:
  `{ name: "רחל", text: "הגבות הכי יפות שהיו לי!", source: "Google" },`

## העלאה לאוויר (GitHub Pages)
1. ב-GitHub: **Settings ← Pages**.
2. תחת **Branch** בוחרים `main` ואת התיקייה `/ (root)`, ולוחצים **Save**.
3. אחרי כמה דקות האתר זמין בכתובת `https://shifragabot-commits.github.io/`.
4. רוצה דומיין משלך (למשל `shifra-gabot.co.il`)? מוסיפים אותו באותו מסך, בשדה **Custom domain**.
